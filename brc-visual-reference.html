当前视觉问题审查

诊断说明：以下问题基于对源代码（globals.css、layout.tsx、各组件）的直接分析。严重程度分为「高」（影响品牌感知）、「中」（体验断层）、「低」（细节打磨）三级。
● 高

字体系统缺失

layout.tsx 没有引入任何 web font。globals.css 的 body 最终 fallback 到 Arial, Helvetica, sans-serif。Geist 字体变量虽然声明了，但没有通过 next/font 正确加载，导致中文完全依赖系统字体，没有设计感。

→ 修复：引入 next/font/google，配置中英文字体对
● 高

颜色体系缺乏品牌感

目前的 red-700 作为主 accent，在 zinc 灰色系中显得突兀而刺眼——对教会网站而言，应该传递温暖、神圣、群体感，而红色缺乏这种温度。amber-500 的 CTA 按钮与 red-700 标题之间也没有清晰的颜色层级逻辑。

→ 修复：建立暖金 + 深绿/深蓝的品牌色系，替换生硬的红色
● 高

各 section 缺乏视觉一致性

首页由若干视觉语言完全不同的 section 拼接：轮播图（深色叠加）、amber-50 的 AlignWithGod section、白底联系表单、深色 3D 档案库……像是几个不同网站拼在一起，没有统一的设计语言。

→ 修复：建立统一的 section 设计模版，规范背景色/分隔方式
● 中

轮播图设计过于基础

MinistryCarousel 使用简单的 bg-gradient-to-t from-black/60 叠加，图片下方的标题字体小、行距密、无衬线字体，缺乏大气感。切换指示点（小圆点）视觉上也很弱。

→ 修复：升级为电影感构图，大号标题 + 衬线字体 + 更精致的指示器
● 中

表单缺乏视觉精致感

HomeContactForm 使用 bg-white/80 背景，输入框是底部单线条设计（仅 border-b），无 focus 动画，提交按钮无圆角（bg-amber-500 方形），整体感觉粗糙。

→ 修复：加入 focus ring、平滑过渡动画、圆角按钮
● 中

排版层级不清晰

页面内字体大小跳跃杂乱：tracking-widest 的 10px 小标签 + 5xl 的大标题 + 普通 text-sm 正文混用，没有经过设计的 type scale。中文内容的字重和行高也未针对中文阅读习惯优化。

→ 修复：建立 8px 基准的 type scale，中文 line-height ≥ 1.8
● 中

Header 与页面内容的视觉关系断层

透明 header 在不同页面表现不一致（部分深色文字、部分浅色文字），滚动后突然变为实色 header 的过渡缺乏 backdrop-blur 等现代效果，过渡感突兀。

→ 修复：统一 scroll 过渡，加入 backdrop-blur + 渐变过渡
● 低

Footer 缺乏品牌表达

bg-zinc-50 的 footer 极为平淡，没有品牌 logo 展示、没有视觉分隔，订阅区块的 input+button 排列也比较生硬，缺乏精致感。

→ 修复：加入品牌 logo 区、更有设计感的分隔线、深色背景选项
● 低

缺乏微交互与动效系统

目前只有 3D 档案库有动画，其他组件几乎没有 hover 状态、page transition、或 scroll-triggered 动画，导致页面感觉静止和廉价。

→ 修复：为导航链接、卡片、按钮添加一致的微交互系统
● 低

SEO Metadata 是占位符

title: "BRC", description: "BRC website"——完全没有品牌表达，也不利于搜索引擎收录和社群分享（Open Graph 图像也缺失）。

→ 修复：完善 metadata，加入 OG image 生成

BRC 视觉更新计划

更新原则：BRC 是教会社群网站，视觉目标应是「温暖、庄重、现代、包容」——不是酷炫的创意机构，也不是冰冷的科技公司。每次更新都要问：「这个改动是否让人感到被欢迎、被接纳？」
Phase 1 · 基础
品牌字体
& 颜色系统
工作量 中
优先级 最高
参考 Steve Schoger

字体升级

  • 在 layout.tsx 中引入 next/font/google，加载 Lora（衬线体，用于标题/圣经经文）和 Inter（无衬线，用于正文和导航），同时配置 Noto Serif SC / Noto Sans SC 作为中文字体
  • 建立 type scale：xs(12) / sm(14) / base(16) / lg(18) / xl(20) / 2xl(24) / 3xl(30) / 4xl(36) / 5xl(48)，中文内容统一 line-height: 1.85
  • 用 CSS 变量 --font-heading 和 --font-body 在 Tailwind config 中注册，替换所有 hardcoded font 声明

颜色系统重构

  • 用 暖金色系（amber/warm gold）替代现有 red-700：primary-900 → #78350f、primary-700 → #b45309、primary-500 → #d97706、primary-100 → #fef3c7，建立完整 10 步色阶
  • 加入 深森绿 作为副色（沉稳、群体感）：secondary-900 → #1a3a2a，用于 footer 背景或 hero overlay
  • 在 globals.css 定义 --color-brand-* 系列变量，同步到 tailwind.config.ts 的 theme.extend.colors
推荐字体组合预览
与神同行 · Align With God
正文使用 Inter，清晰易读，现代感与温度并存。Chinese body text uses Noto Sans SC for optimal readability across bilingual content.

滚动行为升级

  • 透明 header 滚动后改为 backdrop-blur-md + bg-white/80，加 transition-all duration-300，消除突兀的颜色切换

  • 菜单打开时背景加 backdrop-blur 遮罩，提升层次感

MinistryCarousel 升级

  • 图片高度从 h-[420px] 升级为全屏 h-[70vh] min-h-[500px]，创造电影级的视觉冲击
  • 标题字体改为 Lora 衬线体（或 Noto Serif TC），字号放大到 text-4xl md:text-6xl，加入 drop-shadow 提升可读性
  • 渐变叠加从 from-black/60 改为 from-black/70 via-black/30 to-transparent，同时在图片左侧加一条竖向品牌色线条（2px 高光）
  • 切换指示器改为细长横条（progress bar 风格，宽度根据剩余时间动态缩短），更有设计感

AlignWithGod Section

  • 背景从 bg-amber-50 改为更饱和的 bg-stone-100 或深色 bg-stone-900 text-white 方案，让 section 在页面中「锚定」而不飘
  • 数字编号用 font-feature-settings: "onum" 开启 old-style numerals，或直接换为大号罗马数字（Ⅰ Ⅱ Ⅲ），增加神圣感
  • 引用经文部分加入左侧引号装饰（CSS ::before），用品牌金色渲染

Scroll-triggered 动画

  • 使用 CSS @keyframes + IntersectionObserver（或 Framer Motion 的 whileInView），为各 section 标题加入 fade-up 入场动画（translateY(24px) opacity-0 → translateY(0) opacity-1，持续 400ms）
  • AlignWithGod 的 4 个 goal card 加入 staggered 入场（每个延迟 80ms），增加编排感

页面过渡

  • 在 Next.js App Router 中加入 View Transitions API（或 Framer Motion AnimatePresence）实现路由切换的淡入淡出

细节微交互

  • 导航 Logo hover 时轻微 scale（1 → 1.02），Nav links hover 时颜色 + 下划线同时过渡
  • Footer 订阅按钮加入发送动画（点击后图标从「→」变为「✓」，持续 1 秒后复原）

深色 Footer 方案

  • 为各页面添加 structured data（Schema.org 的 Organization 和 Event 类型）
